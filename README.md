# 剧本 → 分镜 解析规范

**中文** | [English](README.en.md)

**适配 Seedance 2.5 · 30 秒分镜组**

> 把小说正文 / 剧本，拆成 AI 漫剧能直接拿去生产的**分镜脚本**与**分镜故事板**。
> 一份从多集实际产出里反复打磨出来的工程规范，不是理论，是踩过坑之后的硬指标。

硬指标按 Seedance 2.5 的单次生成能力标定：**一组 = 一次生成 = 30 秒**，组内 8~11 个内容镜头、单一场景、不转场。换模型或换画幅时改 §1 / §2 / §10 即可，其余条款与平台无关。

## 它解决什么问题

用 AI 视频模型（Seedance、可灵、Veo 等）把小说拍成漫剧时，真正拖垮效率的不是画质，而是**一致性**：

- 同一集里主角的伤疤一会左脸一会右脸
- 上一镜还在桌东侧，下一镜凭空跑到门口
- 长台词拆成两句，第二句整段丢了，肉眼查了五遍才发现
- 每个镜头写得像散文，模型每次理解都不一样，出片靠抽奖

这份规范把这些问题全部压成**可校验的硬指标**：位置以锚点量化到 cm、左右手性逐手写死、每集首组必须回读上一集成品末镜、台词零遗漏用脚本机器核验而不是肉眼抽查。

---

## 核心设计（六条，都是血教训）

**1. 每个分镜组只承载一个场景，组内绝不转场。**
转场只发生在组与组之间。当某场景内容不足 30 秒而需要换场时——**宁可组短于 30 秒**，也不把下一个场景塞进同一组。场景完整性优先于时长完整性。

**2. 位置一律用「锚点 + 相对关系」，不给形容词。**
不写「站在桌边」，写「锚=方桌东侧，立于距东桌沿约 30cm」。文件头必须先设 `## 场景坐标基准`（原点 / 轴向 / 固定物尺寸与长边朝向 / 量距口径），组内只引用不重定义。

**3. 左右必须逐手写死，空着的手也要交代。**
只写「手垂着」＝信息缺失。AI 不会自动补齐另一只手在干什么，缺写即漂移。持物要写全四要素：哪只手 + 握法 + 朝向或高度 + 是否双手协同。

**4. 每集首组的开场设计，必须回读上一集成品的「末组末镜」。**
不得按剧本推断代填，要逐实体核对五项：姿态 / 位置 / 朝向 / 持物 / 生理信号。任一项不符即不合格；上一集晚于本集产出时，取得后必须回填。

**5. 抽象词一律转成可见信号。**
「绝望」写「落泪、颓然瘫坐」；「震惊」写「双眼圆睁、嘴唇微张」。全文核查，不允许抽象词裸用。

**6. 台词零遗漏靠机器，不靠眼睛。**
任何一句台词 / OS / VO 都不得遗漏；长台词拆分后拼接必须 100% 还原。用归一化子串比对做交付前强制关卡——实践中「拆分后只落上半句」是最常见的故障，肉眼抽查极易漏判。

## 快速开始

**只想读**：直接看 [`references/storyboard-spec.md`](references/storyboard-spec.md)，18 个章节，约 1.5 万字。

**想在 Agent 里用**：把本仓库放进你的 skills 目录，或直接把 `SKILL.md` 与 `references/` 一起拷进去。

**想抄作业**：规范 §17 里有一整块可直接套用的【一致性控制】示例，§18 有可运行的核验脚本思路，`scripts/verify_dialogue.py` 是可直接跑的实现。

```bash
# 台词零遗漏核验（支持 .docx 与 .txt 剧本）
python scripts/verify_dialogue.py 原剧本.docx 第1集分镜脚本.md 第1集分镜故事板.md

# 交付前 26 项自检（结构 / 排版 / 手性 / 一致性控制 / 标注 / 台词）
python scripts/check_spec.py 第1集分镜故事板.md \
    --script 第1集分镜脚本.md --baseline 原剧本.docx --ep 1
```

两个脚本都是纯标准库、零依赖，任一违规即退出码 1，可直接挂进流水线当门禁。

`check_spec.py` 输出 26 行 `OK / WARN / FAIL / SKIP`，每条违规带行号或组号。
判不了的检查点一律标 `SKIP` 并说明缺什么参数，不会默认通过——比如不给 `--script`
就不比对双文件，不给 `--baseline` 就不核台词。

> 拿旧稿第一次跑 CHK11（裸写部位词）通常会报出一批历史遗留，属正常：
> 那条铁律是后加的，旧稿没有回溯改。新集从零开始写时应当零命中。

## 适用范围与边界

- **适用于**：竖屏漫剧、AI 视频分镜、需要跨镜头强一致性的连续叙事项目。
- **不适用于**：单张插画提示词、无连续性的短视频切片、需要自由运镜的电影级实拍脚本。
- 规范里出现的「30 秒 / 9:16 / 8~11 镜」是按当前主流 AI 视频模型能力（单次生成 30 秒内、竖屏）设定的硬指标。换模型或换画幅时，改 §1、§2、§10 即可，其余条款与平台无关。
