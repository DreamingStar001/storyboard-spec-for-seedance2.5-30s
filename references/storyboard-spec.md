# 分镜解析规范（剧本 → 分镜 生产标准）

> 适用范围：将「剧本 / 小说正文」拆解为 AI 漫剧可生产的**分镜脚本**与**分镜故事板**。  
> 本规范从多集实际产出中固化，覆盖文件结构、分镜组硬指标、格式字段、忠实剧本铁律与多条表演优化规则。  
> **维护说明**：本规范是「剧本→分镜」解析方向的单一事实来源（single source of truth），持续迭代——用户对解析方向提出的根本性意见会被写入对应章节，并在下方「最后更新」处刷新日期；仅影响单集的临时调整不写入。  
> 最后更新：2026-10-25 · 完整变更记录见仓库根目录 [CHANGELOG.md](../CHANGELOG.md)。

## 0. 文件双交付

每集固定产出两个文件（动作戏密集的集可追加专项版）：

| 文件       | 命名                           | 层级    | 内容                                 |
| -------- | ---------------------------- | ----- | ---------------------------------- |
| 分镜脚本     | `《项目名》第N集分镜脚本（表演优化版）.md`     | 生成单元级 | 场景/角色/道具引用、视频提示词、关键一帧              |
| 分镜故事板    | `《项目名》第N集 分镜故事板（表演优化版）.md`   | 镜头级   | 9:16 竖屏，每组约 10-12 镜，含景别/运镜/构图/进行动态 |
| 动作专项（可选） | `《项目名》第N集 动作场面分镜故事板（专项版）.md` | 镜头级   | 单列动作戏，便于集中设计打斗/追逐                  |

## 1. 整集规格

- **时长**：每分镜组固定 **30 秒**（适配 Seedance 2.5 长视频能力）；单集 = 30 秒 × 组数（通常 5~6 组 = 150~180 秒）。
- **切分**：按剧情节点拆成若干「生成单元 / 分镜组」，**每个分镜组只承载一个连续场景**（见 §2.1 场景单一性原则）；场景切换只发生在组与组之间。
- **画幅**：9:16 竖屏。

---

## 2. 分镜组时长与镜头数硬指标（故事板）

> 历史：原「9 宫格」硬性 9 格规则自 2026-10-23 起改为下方规则，以适配 Seedance 2.5 长视频能力。

1. 每格为 **9:16 竖屏**。
2. 画风统一（项目级，见 §13）。
3. **画面不要有任何字幕内容**——台词写在「进行动态」里，并标注「（画面上不要有任何的字幕内容）」。**例外（系统面板文字须显式呈现）**：系统面板 / 系统光幕显示的文字（系统VO 与系统屏文字，如余额、诊断、抽奖结果等）必须在画面中如实显现，故此类台词**不**附加「（画面上不要有任何的字幕内容）」，由系统面板自身渲染可见文字即可；角色台词 / OS / VO（人物口播）仍照常附加。
4. 角色动作连贯、符合**弥合六法**（见 §15）。
5. **每个分镜组固定时长为 30 秒**；**内容镜头 8~11 个**（不设「高角全景衔接」格，全组均为内容镜头，每组合计 8~11 镜，按 30 秒时长填满）。

**补满规则**：每组**全部为内容镜头**（自 2026-10-25 起取消「高角全景衔接」格），以 8~11 个内容镜头填满 30 秒，**不再强制用空白白板补满 9 格**——白板仅作极端兜底（内容镜头不足时临时占位），正常情况下以充实内容镜头取代，以保证 30 秒时长被充分利用。

### 2.1 场景单一性原则（组内禁转场 · 2026-10-23）

- **组内单一场景**：每个分镜组只承载**一个连续场景**的镜头；**同一组内严禁出现场景切换 / 转场**——无论硬切、淡入淡出、匹配剪辑，只要换场即违规。
- **转场只发生在组间**：不同场景的内容必须分到**不同的分镜组**，组与组之间以【一致性控制】（§17）衔接（其场景锚点须显式标注跳转，如「卧房 → 兽栏」）。
- **30 秒时长的例外（场景边界优先）**：当某场景可用的镜头内容**不足 30 秒**而需在该处转场时，该分镜组可在不足 30 秒处收束——**不必为凑满 30 秒而把下一个场景塞进同一组**。即「**场景完整性 ＞ 时长完整性**」：宁可组短于 30 秒，也绝不组内转场。
- **底层依据**：与 §15 弥合六法「单一空间路径」（同组镜头空间连续不跳场）一致，是本原则的底层方法支撑。

## 3. 分镜脚本文件结构（生成单元级）

```
文件头（场景 / 人物 / 资产图库根目录 / 结构说明 / 备注）
└─ 资产图库索引（场景 / 角色 / 道具 / 系统）
└─ 切分单元说明（拆几组、整集约 X 秒、主线、长台词拆分说明）
└─ 分镜脚本
   ├─ 【一致性控制】（开场设计 · 跨集衔接：上一集末组 → 本集首组）★ 见 §17
   └─ 【分镜组号】0X（30秒）
      ├─ 导语
      ├─ 一、场景描述和角色道具引用（场景 / 角色 / 音色 / 道具 / 前置状态）
      ├─ 二、视频提示词（进行动态 / 运镜设计 / 补充描述 / 生成要求）
      └─ 三、关键一帧（A / B / C 或 继承 X 锚点）
   └─ 【一致性控制】（组间衔接：开场站位 / 角色状态 / 物品状态）★ 见 §17
   └─ 【分镜组号】0(X+1)（30秒）
      └─ ……
```

> **结构说明**（文件头固定文字）：本文件按「分镜组号 → 一、场景描述和角色道具引用 → 二、视频提示词（进行动态/运镜设计/补充描述/生成要求）→ 三、关键一帧」组织；画风统一为「…」，负面提示词禁止塑料感/卡通/畸变。单句台词控制在 5 秒内（约 25 字以内）说完，过长台词拆分为多句、分别落在不同镜头。  
> **组间一致性控制**：每集首组之前须设一个【一致性控制】（开场设计，跨集衔接上一集末态，见 §17），其后相邻分镜组之间亦须插入【一致性控制】栏目（字段与用法见 §17），显式锁住角色/站位/状态/道具/场景的组间与跨集延续，避免跳变。

## 4. 分镜故事板文件结构（镜头级）

```
文件头（分镜组时长/镜头数硬指标 + 进行动态定义 + 白板说明 + 长台词拆分 + 参考源）
└─ 【一致性控制】（开场设计 · 跨集衔接：上一集末组 → 本集首组）★ 见 §17
└─ 分镜组 0X（30秒）
   ├─ 角色、场景和道具引用（角色引用只列姓名不标衣着/年龄身高；道具引用只列名不标尺寸；年龄身高与道具尺寸统一在「进行动态」首次出现处标注）
   ├─ 【镜头1~11】内容镜头（每组 8~11 个）：场景 / 景别 / 运镜 / 构图 / 进行动态（…）
   └─ （白板仅极端兜底，正常不设；不设「高角全景衔接」格）
└─ 【一致性控制】（组间衔接：开场站位 / 角色状态 / 物品状态）★ 见 §17
└─ 分镜组 0(X+1)（30秒）
   └─ ……
```

> **分镜组时长与镜头数硬指标**（文件头固定文字，可据项目微调画风）：
>
> 1. 每格为 9:16 竖屏；2. 画风「…」；3. 画面不要有任何字幕内容；4. 角色动作连贯、符合弥合六法；5. **每组固定 30 秒、内容镜头 8~11 个**（不设高角全景衔接格，合计 8~11 镜）。  
>    「进行动态」以连贯叙述一次性交代：谁（主体）、在何处站位（站位）、做了什么（动作）、神情如何（表情与神态）、说了什么（台词，直接写出具体文字、画面不出屏）。  
>    每个分镜组固定 30 秒，内容镜头填满 8~11 个（不设「高角全景衔接」格）；空白白板仅作极端兜底，不再强制补满 9 格。  
>    单句台词控制在 5 秒内（约 25 字以内）说完，过长台词拆分为多句、分别落在不同镜头。

### 4.1 排版一致铁律（根本性新增 · 2026-10-25）

- **镜头标题**一律写作 `【镜头N】名称` 纯文本，不加 `**`、`#`、`>`，标题末尾不加句号。
- **镜头内字段与正文**（场景 / 景别 / 运镜 / 构图 / 进行动态 / 台词行）一律不加粗、不使用任何标题级别，字号与粗细必须与其余镜头完全一致。
- **组间分隔线**固定写作单独一行 `---`，且**上下各留一个空行**。严禁紧贴正文（如 `-----` 直接接在正文下一行）：Markdown 会把紧邻的上一段解析为**二级标题（Setext Heading）**，导致该镜头的末行字号变大并加粗，与其它镜头不一致。
- **允许出现的加粗仅两处**：文件头的硬指标引用行（`> **分镜组时长与镜头数硬指标**…`）与每组 `**角色、场景和道具引用**：` 标签行；除此之外全文不得出现 `**`。
- **交付前检查**：脚本与故事板两份文件逐一确认——无孤立 `**`、无 `#` 级标题混入镜头正文、所有分隔线上方为空行。

## 5. 进行动态六维字段（核心格式）

「**进行动态（主体、站位、动作、表情、神态、台词）**」——一次连贯叙述交代六个维度，单行排列、不换行，便于复制：

| 维度 | 含义                 |
| -- | ------------------ |
| 主体 | 谁在做                |
| 站位 | 在何处站位              |
| 动作 | 做了什么（可见肢体/位移）      |
| 表情 | 面部表情（眉/眼/嘴等）       |
| 神态 | 整体神气、气质状态          |
| 台词 | 说了什么（直接写出文字，画面不出屏） |

例：

> 角色A（21岁，178cm）慢悠悠走过去、蹲下身、还吹了吹指甲上的灰。

## 6. 关键一帧稀疏策略（A / B / C 三类）

关键一帧**不每组都画**，只在空间或末态发生变化的组真实输出，其余组写「（继承组 XX X 锚点）」避免重复出图：

| 类型            | 含义              | 通常出现位置      |
| ------------- | --------------- | ----------- |
| **【A｜空间定场帧】** | 建立本集/本段空间与开场状态  | 仅第 01 组     |
| **【B｜末态锚点帧】** | 关键转折/收服/高潮的末态定格 | 仅关键组（如收服灵兽） |
| **【C｜末态悬念帧】** | 本集收束、悬念接下集      | 通常末组        |

> 历史惯例：某 14 组项目里仅 01/07/10/13 四组需真出关键一帧；现按「是否发生空间/末态变化」判断，宁缺毋滥。

## 7. 忠实剧本铁律

- **台词零增删改**：剧本所有台词 / OS / VO 逐字保留，不可加假台词、不可漏。
- **剧情主体不变**：只可增添可见的动作/神态/表情细节，不可改剧情走向。
- **称谓矛盾保留**：剧中口误（如角色互相以化名相称、而叙事使用本名）按原文保留，不擅改。
- **未出场不纳入**：剧本「人物」栏列出但本集正文未实际出场的角色，不进分镜，并在备注说明。

---

## 8. 抽象词 → 可见信号（零残留）

所有情绪/状态形容词必须转成**可见、可拍**的面部/肢体信号，全篇核查确保无抽象词裸用：

| 抽象词       | 可见信号示例              |
| --------- | ------------------- |
| 绝望        | 落泪、颓然瘫坐             |
| 不可置信 / 震惊 | 双眼圆睁、嘴唇微张           |
| 坚定        | 改具体神态/动作，避免「语气坚定」裸用 |
| 惧色        | 瞳孔骤缩、后退半步、喉结滚动      |
| 痛心        | 眉头紧锁、咬牙             |

---

## 9. 跳切规避

同组相邻**同主体**镜头，须满足其一，避免跳切：

- 切换主体；**或**
- 拉开 **≥ 30° 角度** / 改变**景别**。

不得同一主体同一角度连续两个镜头。

## 10. 分镜组时长标注（固定 30 秒）

每个分镜组固定时长为 **30 秒**（适配 Seedance 2.5 长视频能力），序号后统一标 `（30秒）`，不再使用可变的「约N秒」：

- 脚本：`### 【分镜组号】01（30秒）`
- 故事板：`## 分镜组 01（30秒）`

> 适用范围：所有新项目。「首组跨集开场设计」（§17 · 2026-10-24）同样以新产出为准——新解析的集须包含首组开场设计；早期已产出的旧集保持原可变时长、不回溯，除非明确要求。
> **例外**：若某场景内容不足 30 秒而需在该处转场，该组可短于 30 秒（见 §2.1 场景单一性原则）——场景边界优先于 30 秒时长，不得为凑时长跨场景塞镜头。

---

## 11. 长台词拆句（新项目适用）

- 单句 **> 25 字（约 5 秒）** 需拆成多句，分别落在不同镜头。
- **只切分、不增删改字**；拆后每句确保 5 秒内说完。
- 例：角色A「绝症 + 药费」拆两句；角色E「洪福齐天 + 横扫四方」拆两句。

## 12. 角色信息标注

- **每组必标（落点＝进行动态）**：每个分镜组内，**每位登场人物**的姓名都须**在组内「进行动态」首次出现处随附一次「（年龄，身高cm）」**标注（如 `角色A（21岁，178cm）擦了擦手…`），便于 AI 视频模型锁定人物比例；该标注在组内只出现一次（首次），后续同名不再重复。每组开头的「角色引用」行只列姓名（可附晕死 / 留场等状态词），**不标年龄身高、不标衣着**。
- **灵兽 / 非人角色**以**体型**标注代替身高（如「体长≈1.5m」「高约两米」），同样在组内「进行动态」首次出现处标注一次（如 `黑毛猪（体长≈1.5m）躺在干草堆上`）。
- **角色引用行只列姓名（不标衣着、不标年龄身高）**：「年龄,身高cm」与「灵兽体型」统一在「进行动态」首次出现处标注（见上两条）；「角色引用」行只列人物姓名（可附晕死 / 留场等状态词），**不标任何衣着 / 服饰**（如「青布医袍」「月白道袍」等）——服饰设定统一在**资产图库索引·角色**与资产图中指定，引用处剥离。
- 年龄 / 身高 / 体型若无官方人设，由解析方按项目调性合理设定，并在备注标明「待校准」。

### 12.1 左右手性铁律（根本性新增 · 2026-10-25）

**原则**：凡左右可分者，一律带「左 / 右」；**裸写即不合格**。

- **必须带左右的部位**：手 / 掌 / 指 / 腕 / 臂 / 肘 / 肩 / 腿 / 膝 / 脚 / 眼 / 耳 / 鬓角 / 腰侧 / 怀内 / 衣袋 / 刀鞘挂侧。禁写「手垂着」「双臂垂放」「刀挂腰间」「鬓角数缕白发」（后者须写「鬓角每侧约 4-6 缕白发」）。
- **空着的手也要写明**：只交代一只手＝信息缺失，另一只手必须显式给出状态（`左手搭左膝、掌心朝下` / `左手空垂于左身侧` / `左掌托扶盘沿`）。AI 视频模型不会自动补齐「另一只手在干什么」，缺写即漂移。
- **左右指「角色自身的左右」**：一律以角色身体为准，**不得用「画面左 / 画面右」作身体定语**（角色转身即错）。画面方位只能出现在「画面落位」「视轴与机位」两处，且须给出换算基准（如「机位朝北时：画面右 = 场景东侧」）。
- **持物四要素（每次持物必写全）**：`哪只手 ＋ 握法（握 / 捏 / 托 / 执 / 端 / 夹 / 提 / 攥 / 按）＋ 朝向或高度（距地 cm / 距锚 cm）＋ 是否双手协同`。例：`右手虚扣桌沿、掌心朝下（距桌沿约10cm）`、`双手端盘平举于胸前（盘底距地约110cm；右掌托盘底东半、左掌托扶盘沿西侧）`。
- **道具挂载须写侧别**：`腰刀` → `角色C左腰侧（带挂）、刀柄朝前上方（握柄距地约105cm）`；`储物戒` → `右手无名指`；`银针` → `右手拇食指捏持`。
- **适用范围**：全文所有字段——「进行动态」「构图」「关键一帧」「运镜」与【一致性控制】。

## 13. 画风与负向提示（项目级锁定）

| ---- | ------------- |

## 14. 资产图库引用

- 文件头标注**资产图库根目录**（如 `项目名-第N集-资产/`）。
- **资产图库索引**单列：场景 / 角色 / 道具 / 系统，统一命名便于后续文生视频 unit 化复制粘贴。
- 道具按「**有图才提取**」：剧本明确出现才入索引。

## 15. 弥合六法（动作连贯底层方法）

为确保角色动作跨越镜头连续、不割裂，遵循六法：

1. **主语贯穿**：同一动作链主语不跳。
2. **因果焊接**：上一镜末态即下一镜起态，因果直接焊接。
3. **单一空间路径**：同组镜头空间连续不跳场。
4. **末态被动结果**：动作以被动/完成态收尾，不悬空。
5. **删感官铺垫**：不写「他感到…」「似乎…」等感官铺垫，直接给动作。
6. **末态对齐关键一帧**：组的末态镜头对齐该组关键一帧锚点。

## 17. 组间一致性控制（根本性新增 · 2026-10-23）

为强化分镜组之间、以及分镜集之间的时空与状态连贯，每个「分镜组」与下一个「分镜组」之间、**每集第一个分镜组之前**，均**必须插入一个【一致性控制】栏目**，显式记录衔接状态，使下一组/下一集的角色、站位、状态、道具、场景尽量延续上一组/上一集结束时的状态。

**位置**：每集首组之前须设一个【一致性控制】作为本集「开场设计」（跨集衔接：上一集末组结束状态 → 本集首组），其后相邻两组之间各设一个；末组之后可省略（本集收束态由末组内容本身描述，本栏目不再单列「结束状态」字段）。

★ **职责边界：只做「承上启下」（根本性新增 · 2026-10-25）**：本栏目是**交界面上的状态声明**——只回答一件事：**上一组的收束态如何交棒为下一组的起手态**。据此划定三条边界：

- **只锁交界，不锁过程**：本栏描述的是「下一组镜头 1 起手那一格」的客观状态（及与之相等的上一组末镜收束态），**不管组内中途如何变化**。
- **不承担组内动作交接**：谁把盘子放下、什么时候收刀、谁先转身——一律**不属本栏职责**，归 §9 跳切规避与 §15 弥合六法在镜头层解决；本栏不得为此补写过程动作，镜头也不必逐一复述本栏字段。
- **合格判定只有两条**：① 本栏每个值**与上一组末镜的实际末态相符**；② 与**下一组镜头 1 的起手态相符**。二者相符即合格——不因「组内没演到」而判不合格。

**首组跨集开场设计（根本性新增 · 2026-10-24）**：

- **每集首组之前必设**：作为本集的「开场设计」，把上一集末尾的客观状态「接棒」到本集首组的开局，避免跨集跳变（如角色凭空换装、道具消失、站位漂移）。
- **字段用法与本栏目完全一致**（去剧情 / 锚点相对关系 / 生物化 / 切片化四大铁律同样适用）：
  - **开场站位 / 角色状态 / 物品状态**：写本集首组开场的客观快照，**须等于**上一集末组结束态（显式延续，即跨集基准）；仅取两集交集实体。若跨集发生空间归并 / 跳转（如前集末在外屋、后集首组在大厅），须在场景锚点处注明归并与各角色去向，其余字段仍按锚点相对关系记录。
- **首集（无上一集）**：以「本剧开场初始基准」作为「开场站位 / 角色状态 / 物品状态」的开场快照（如首集：角色A昏迷卧床、尚未睁眼）；无跨集延续问题。
- **跨集基准缺失**：若上一集尚未产出（如工作区只含某一集、缺其前一集），该栏「开场站位 / 角色状态 / 物品状态」先以本集首组初始态作为临时基准，并标注「待回填第 N-1 集末态」；取得上一集后须回填并核对。
- **与组内/组间一致性控制的区别**：组内禁转场（§2.1）、组间【一致性控制】锁同集相邻组；本「开场设计」专门锁**集与集之间**的首尾衔接，是 §17 在「集」尺度的延伸。
- ★ **必须回读上一集成品（根本性强化 · 2026-10-25）**：本栏**不得按剧本推断写出**，须以**上一集成品的「末组末镜结束态」为唯一依据**，逐实体核对五项——**姿态（站/坐/跪/卧）· 相对锚点的位置与距离 · 朝向 · 持物（左手/右手分别）· 生理信号**；任一项不符即为不合格。若上一集成品尚未产出，可暂以剧本末态作临时基准，但**必须在上一集成品产出后立即回填**；回填只改该集开场设计与首组内与之冲突的动作描写，不属改动历史剧情。若剧情需要在跨集间隙发生状态变化，**必须在首组内用可见动作完成过渡**（如「立于桌东侧 → 撩袍落座」），不得直接以变化后的状态开栏。

★ **实体交集原则（范围铁律 · 根本性新增 2026-10-25）**：本栏目**只描述上一分镜组与下一分镜组共同存在**的人物、场景、道具——即两组的交集。**不在下一组出现的实体（已离场 / 已销毁 / 尚未登场）一律不写入本栏目任何字段**；若某实体只存在于上一组而不在下一组，说明它在组间衔接中无延续价值，必须剔除。开场设计块同理：只取「上一集末组」与「本集首组」交集内的实体。

本栏目以「客观快照」为核心，遵循四大铁律（首要）：

1. **去剧情**：本栏目只描述组切换这一刻的客观快照（位置、姿态、生理信号、道具落点），**严禁叙述情节发展、因果、未来态**；禁止剧情动词（转入/转念/开始/将/欲/从…转入…）与主观情绪判词（笃定/期待/果断/惊恐）。写「眉心微蹙、呼吸平稳、右手虚握」，不写「情绪笃定、转入治疗操作」。
2. **物理化（锚点相对关系）**：位置一律用「锚点 + 相对关系」表达。人物 → 以场景固定物为锚（墙/栏柱/门/窗/桌/床/灶等不动物），给「相对锚的方位 + 距离 + 高度层级（站/坐/蹲/跪/卧）」；物品 → 以人物（或场景）为锚，给「相对锚的方位 + 距离 + 高度」。人物/物品间也可互锚；锚点首选最不易跨镜漂移的固定物。
3. **生物化 / 客观化**：角色状态只写可观测生理与体表信号——呼吸节律（平稳/急促/屏息）、瞳孔（散大/聚焦）、面部肌肉（眉头紧锁/咬肌绷紧）、肢体（握拳/虚握/垂放）、体表（血迹位置与面积、伤口尺寸、泥污范围）。不写主观情绪词。
4. **切片化**：每条描述拆为可独立校验的原子事实（方位/距离/高度/朝向/体表各成切片），便于跨镜逐条比对「变没变」。
5. **不描述服饰**：本栏目**不写服装款式/颜色/材质**（如「青布医袍」「玄色锦袍」「灰布长衫」「月白道袍」「灰蓝医袍」「玄色劲装」）及**服饰部位词**（前襟/袖口/衣摆/衣袖）——服饰设定统一在**资产图**中指定，【一致性控制】只描述可观测的体表/生理/道具/空间几何状态；若须记录衣物上的**血迹/泥污等痕迹**，按「身体部位 + 痕迹」描述（如「左胸下血点」「下身沾泥」），**不出现任何服饰名称**。
6. **不引集数（2026-10-25）**：本栏目**不出现任何具体集号**（如「延续第4集末」「第5集末态」「第N集」）——衔接关系以「上一组 / 下一组」「跨集基准」概念表达即可，集号属剧务编号，不应进入画面描述；跨集基准的必要说明放在文件头「切分单元说明」，本栏目只写客观状态。
7. **量化无歧义（2026-10-25）**：锚点相对关系一律给**可复现数值**——距离 / 高度 / 尺寸精确到 **cm**，数量精确到 **个 / 处 / 缕**，时间精确到 **秒 / 分**，面积 / 直径给具体数值；**禁用模糊量词**（些许、若干、数缕、微促、半尺、1 步、1 尺、旁边、附近、较多）。例：「绷带在腿部」不合规，应写「绷带缠于右大腿中段，长≈40cm、宽≈8cm，覆盖伤口（伤口≈长3cm），绷带外缘距膝盖≈12cm」。
8. **手性与持物明细（根本性新增 · 2026-10-25）**：本栏目对**每个角色逐手分别记录**，左手、右手各自写「部位 · 掌心/指朝向 · 持物 · 落点（距锚 cm）」，不允许出现未交代的手（空手也要写 `左手空垂于左身侧、掌心朝内、距左大腿约12cm`）。每个道具必须写清「**由谁的哪只手 · 以何握法持有 · 距地或距锚多少 cm**」；无人持有的道具写「落于何处（桌面 / 地面 / 鞘内）+ 距锚距离」。**所有左右一律为角色自身左右**，禁止以画面左右指代身体部位（细则见 §12.1）。典型写法：

```
  · 角色A：锚=包厢方桌东侧，立于距东桌沿约30cm、躯干面朝西（朝角色C）；右手垂于右身侧、掌心朝外（距右大腿约15cm）；左手垂于左身侧、掌心朝内（距左大腿约12cm）
  · 双手端盘：右掌托盘底东半、左掌托扶盘沿西侧，盘底距地约110cm
  · 腰刀：锚=角色C左腰侧（带挂），已归鞘（刃身全在鞘内）、刀柄朝前上方（握柄距地约105cm）
```

9. **视轴与机位高度（根本性新增 · 2026-10-25）**：每块「开场站位」的**最后一条**固定增设 `· 视轴与机位（9:16）`，五项必填，缺一不可：

   | 项 | 写法 | 作用 |
   | -- | -- | -- |
   | 机位方位 + 距离 | `机位=包厢南侧、距桌心约2.4m` | 锁摄影轴与场景锚点的关系，须与「画面落位」自洽（机位朝北时画面右=场景东侧） |
   | 机位高度 | 距地 cm | 锁「人物越拍越矮 / 越拍越俯」的漂移 |
   | 俯仰角 | `+` 仰拍 / `−` 俯拍，精度 ±1° | 须与「机位高 − 主体眼高」**同号**，可由 Δh 与距离复算（`atan(Δh/距离)`） |
   | 视轴指向 | `视轴→角色A面部` / `→两人视线交汇点（桌心上方约20cm）` / `→盘中肘子` | 锁构图重心，防主体跑偏 |
   | 角色眼高与高差 | `角色A立姿眼高≈166cm（与机位高差 +16cm）` | 使俯仰可校验，且跨镜人物比例一致 |

   机位高度基准（眼高 ≈ 身高 × 0.93）：站姿平视 ≈ 主体眼高；坐姿平视 ≈ 110~120cm；桌面平视 ≈ 90~100cm；低机位 / 桌底 ≈ 30~60cm；大俯拍 ≈ 220~260cm。角色视线的**俯仰角也要给值**（如 `角色C→盘中肘子（俯角约25°）`），避免「同一组内一人平视、一人突然俯视 45°」。

10. **场景坐标基准与量距口径（根本性新增 · 2026-10-25）**：本栏目所有 cm 值必须**可复算**，因此**文件头须一次性定义坐标基准**，组内只引用、不重定义（本节标题 `## 场景坐标基准（唯一事实来源）`）：

    | 项 | 必写内容 |
    | -- | -- |
    | 原点 | 每个场景取一个固定物（如「方桌桌面中心的地面投影」） |
    | 轴向 | x 轴向东、y 轴向北、z 轴为离地高度（cm） |
    | 固定物尺寸与**朝向** | 如「方桌 ≈120cm（南北长）×70cm（东西宽）、桌面高 75cm」——**长边朝哪条轴必须写明**，否则「距东/西桌沿 35cm」与「距南/北桌沿 15cm」谁对谁错无法判定 |
    | 量距口径 | 「距东/西/南/北桌沿约 Ncm」＝沿该桌沿法向的垂直距离；「距桌心约 Ncm」＝直线距离；「相距约 Ncm」＝两锚点直线距离 |

    **同一量唯一性**：同一实体在同一交界时刻的距离 / 高度 / 角度**只许有一个值**；跨块复述同一站位时必须逐字同值（不得一处写 1.5m、另一处 1.4m）。由两个站位推出的视线距离须与实际站位自洽（如「东桌沿 30cm ＋ 桌宽 70cm ＋ 西桌沿 60cm = 1.6m」，不能写 1.5m）。**部位描述与数值不得互相否定**：写「扣桌沿」就不能同时写「距桌沿 10cm」，应写「压于东桌沿内约 10cm 处、指尖朝桌心」。

| -------- | ------------------------------------------------------------------- |
| **开场站位** | 下一组开场时各角色的**以场景为锚的相对位置** + 9:16 画面落位 + 体态朝向视线，**须等于**上一组结束状态；每个角色**逐手分别记录**（左/右手，见第 8 条）。见下方「锚点相对关系」 |
| **视轴与机位** | 下一组开场时的**机位方位 / 距主体距离 / 机位高度 / 俯仰角 / 视轴靶点** + 角色眼高与高差；固定写在本块「开场站位」末条（见第 9 条） |

**锚点相对关系写法（开场站位 / 物品状态的核心）** —— 用「锚点 + 相对关系」表达位置，让 AI 视频模型拿到的是可重建的几何约束而非散文：

```
- 开场站位（人物以场景为锚）：
  · 角色A：锚=兽栏北栅栏，栅外 0.5 步、蹲姿、面朝栏内（3/4 侧脸朝南）；右手垂膝前、虚握
  · 黑毛猪：锚=栏中南侧干草堆，卧草堆东缘、四蹄朝西、头朝北；胸廓随呼吸缓起伏
  · 画面落位（9:16 上/中/下 × 左/中/右）：中下区 角色A蹲姿上半身为主体；猪栏占中上区
  · 体态/朝向/视线：角色A蹲姿·3/4 侧脸朝栏；视线 角色A→黑毛猪

  · 红泥球：锚=角色A右手，握于掌心、距地 0.3 米
  · 系统光幕：锚=角色A视野前 1 米半空，半透蓝、仍显
- 角色状态（生物化客观快照 + 持续特征锁定）：
  · 角色A：蹲姿，眉心微蹙，呼吸平稳，右手虚握泥球；前胸下暗红血点 2 处（Ø≈1cm，位于左胸下）
  · 黑毛猪：侧卧，耳廓微动，眼半睁，鼻翼随呼吸张合，臀后草屑若干
```

- **场景锚点**：先钉死"同一场"，标注是否 = 上一组结束状态；只有空间跳转/时间跳跃才例外说明。
- **人物以场景为锚**：每个在场角色绑定一个场内固定物，给「相对锚的方位 + 距离 + 高度层级」，解决"谁在谁旁边、距哪多远"的跨镜错位。
- **物品以人物（或场景）为锚**：每个道具绑定一个人物或固定物，给「相对锚的方位 + 距离 + 高度」。
- **画面落位**：用「上/中/下 × 左/中/右」标主体在 9:16 画幅内的构图区，解决"上一镜中景、下一镜突然全景"的跳变。
- **体态 / 朝向 / 视线**：锁 坐/跪/站/卧/蹲姿 + 面镜/侧脸/背镜 + 看向谁，解决姿态突变、视线接不上。
- **持续特征锁定**：伤痕/血迹/泥污的精确位置 + 范围 + 形态单列，这是 AI 视频最易跨镜崩坏的，必须钉死。

**使用规则**：

1. **开场站位必须显式等于上一组结束状态**：开场站位 · 场景锚点 须写「（= 组 N-1 结束状态）」做显式等号；只有空间切换（内屋→外屋）、时间跳跃等必须变化时，才例外并在场景锚点处注明差异与原因（注明哪些角色未同框、在何处）。
2. 场景锚点首选场内固定物；人物/物品锚点首选最稳定的参照。
3. **去剧情铁律优先于一切描述**——任何「转入/转念/将/欲/从…转入…」类句子必须从本栏目删除，只保留可观测的客观快照。
4. 该栏目是「跳切规避」「弥合六法·单一空间路径」的**结构化落地**——交付前须逐组核对衔接无误。
5. 脚本与故事板**双文件**均须包含【一致性控制】，且两处记录一致。
6. **实体交集原则**：本栏目只写「上一组 ∩ 下一组」共同存在的实体（人物/场景/道具）。凡只存在于上一组、不在下一组出现的实体（离场/销毁/未登场），一律剔除，不写入任何字段。开场设计块取「上一集末组 ∩ 本集首组」交集。

## 18. 台词零遗漏铁律与核验流程（根本性新增 · 2026-10-23）

**铁律**：分镜产出中**任何一句剧本台词、OS、VO 都不得遗漏或丢失**；长台词按 §11 拆分时，必须保证拆分后的所有片段**拼接后 100% 还原原文、零字符缺失**——只切分、不丢弃任何一个片段。

**为什么单列**：实践中最易发生的故障是「长台词拆分后只落了上半句、下半句整段丢失」，肉眼抽查极易漏判。须以机器核验替代肉眼，作为交付前强制关卡。

**交付前强制核验流程（不可跳过）**：

1. **抽取基准**：从原始剧本中逐段列出全部 OS / VO / 台词（含系统音【】内的文字），作为基准清单。
2. **去噪归一**：对基准句与文件内台词，统一去除标点、空格、引号、【】、括号等，仅保留中文字符序列。
3. **抽取文件台词**：用正则从脚本与故事板两份文件中抽出所有引号内台词文本，按出现顺序拼接成一条归一化串。
4. **逐段比对**：基准清单中每一句归一化串，都必须作为**连续子串**出现在两份文件的拼接串中（拆分片段须在文件中相邻出现，方可拼成连续子串；若被其他镜头插入则需调整拆分落点）。
5. **判定**：任一句缺失或仅部分出现 → **判定不合格，禁止交付**，定位缺失片段并补齐后再核验，直至 14/14（或全集数）全部 OK。

**核验脚本参考（Python 正则思路）**：

```python
import re
# 基准：originals = [原始每段OS/VO/台词]
def norm(s): return re.sub(r'[\s，。！？、：；…""''【】（）()「」\-—]', '', s)
for f in [脚本路径, 故事板路径]:
    txt = open(f, encoding='utf-8').read()
    quotes = re.findall(r'"([^"]*)"', txt)      # 抽出所有引号内台词
    joined = norm(''.join(quotes))
    for o in originals:
        assert norm(o) in joined, f"缺失：{o}"   # 不通过即不合格
```
